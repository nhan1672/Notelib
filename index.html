Rule editor

Chưa nạp file
Nhập file rules.json ở góc trên bên trái để bắt đầu, hoặc bấm "Rule mới".

Mọi rule không được bạn mở/sửa sẽ giữ nguyên 100% khi xuất lại - kể cả field lạ mà công cụ này chưa có ô nhập riêng.
